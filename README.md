# 接入点切换器

为 SillyTavern 的“聊天补全 → 自定义（OpenAI兼容）”保存多组接入点网址和 API 密钥，选择名称后点击“切换”。模型继续在酒馆原来的位置选择；插件不保存、不切换模型、预设或生成参数。

## 安装

需要 SillyTavern 1.18.0 或以上版本，不依赖酒馆助手，不需要后端插件或额外依赖。

在酒馆的扩展管理里选择“安装扩展”，粘贴下面这一行仓库地址：

```text
https://github.com/cjhkcjgk3-sys/st-endpoint-switcher.git
```

安装完成后刷新酒馆。不需要填写分支名。

也可以手动将整个 `st-endpoint-switcher` 文件夹放到酒馆的 `data/default-user/extensions/` 目录，然后刷新酒馆。多用户安装放在对应用户的 `extensions` 目录。

进入 API 连接，选择“聊天补全 → 自定义（OpenAI兼容）”，在自定义接入点网址上方可以看到“接入点切换器”。

## 使用

- 新增：填写名称、基础网址、API 密钥，点击“保存并切换”。
- 保存当前：记录酒馆已经配置的接入点和当前密钥，补一个名称即可保存。
- 切换：选择已保存的名称，点击“切换”，网址和密钥一起切换后交给酒馆原生连接流程。
- 编辑：修改网址或名称；密钥留空保持不变，填入新密钥则替换本条引用。
- 删除：只删除接入点记录，不删除酒馆原生密钥。

网址保持原样保存，不自动添加 `/v1`；按照中转站要求填写基础网址，不包含 `/chat/completions`。

## 保存位置与兼容性

API 密钥通过酒馆原生密钥管理器保存在当前酒馆服务器。插件设置只保存名称、网址和密钥标识，不把密钥正文复制到插件设置或浏览器本地存储；跨设备访问同一酒馆服务器可使用同一组记录。

第一版仅处理“自定义（OpenAI兼容）”，不处理 Google、Claude 原生来源的反向代理。仅在主动点击切换时启动酒馆原生连接检查，不主动生成测试消息。

兼容基线为 SillyTavern 1.18.0 的原生密钥接口 `/scripts/secrets.js` 与自定义接入点页面字段。

已在隔离 SillyTavern 1.18.0、Chromium 153 环境测试：网址与密钥配对、模型与预设保持、刷新后保存、失败恢复、热停用与启用、手机窄屏布局。验证使用本地模拟中转站，未调用付费模型。
